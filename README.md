# Projeto-Sintaxe-basica-JAVA

Projeto de um sistema bancário no terminal desenvolvido em Java com o objetivo de treinar lógica de programação e sintaxe básica da linguagem Java.

---

# Objetivo do projeto

Este projeto foi criado para praticar conceitos fundamentais da programação em Java sem utilizar Programação Orientada a Objetos (POO).

O sistema simula operações bancárias básicas através do terminal, permitindo o treinamento de estruturas essenciais da linguagem.

---

# Conceitos praticados

- Variáveis
- Operadores matemáticos
- Entrada de dados com `Scanner`
- Estruturas condicionais (`if`, `else if`, `else`)
- Estruturas de repetição (`while`, `for`)
- Métodos
- Tratamento de exceções (`try/catch`)
- Lógica de programação
- Manipulação de saldo e operações bancárias

---

# Funcionalidades

O sistema possui funcionalidades como:

- Ver saldo
- Depositar dinheiro
- Sacar dinheiro
- Transferir valores
- Visualizar extrato
- Encerrar sistema

---

# Tecnologias utilizadas

- Java
- Terminal/Console
- IDE de preferência do usuário
